### Homework #17

Вам потрібно написати свої версії функцій 
-indexOf, 
-lastIndexOf, 
-find, 
-findIndex, 
-includes, 
-every,
-some. 

Вимоги:

Використання допоміжних методів масивів заборонено, якщо щось потрібно то треба писати самим. Або взяти з файлів уроку.
Всі функції мають лежати в окремих файлах
В файлі з кожною фукнцією має бути 2 приклади її використання
В файлі з кожною функцією, над її кодом, має бути опис JSDoc (можна генерувати через AI після написання функції, або писати самим.)
