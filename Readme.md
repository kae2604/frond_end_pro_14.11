### Homework #4

Користувач заходить у «магазин» (сторінка з вашим скриптом 😄). Скрипт запитує через prompt:
Початкова ціна товару
Розмір знижки у відсотках (наприклад, 10, 15, 20)
Потім скрипт:
Перетворює введені значення в числа.
Перевіряє, що обидва значення коректні (не NaN, не менші за 0).
Обчислює ціну зі знижкою.
Виводить через alert щось на кшталт: "Початкова ціна: 100 грн, знижка: 15%. Ціна зі знижкою: 85 грн."
Обов’язково:
Використати тільки примітиви (number, string, boolean).
Використати мінімум один if для перевірки валідності введених даних:
Якщо користувач ввів щось некоректне → alert("Помилка вводу").
